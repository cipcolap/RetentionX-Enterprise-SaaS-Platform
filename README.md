# RetentionX-Enterprise-SaaS-Platform
Autonomous AI-powered churn prevention platform for B2B SaaS. Features real-time unit economics simulation (LTV/CAC, ARR), ML risk forecasting with SHAP explanations, dynamic cohort heatmaps, automated agentic playbooks, and Gemini API strategic insights. Complete with a React/Tailwind frontend and FastAPI/CatBoost backend.
